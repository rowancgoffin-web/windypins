Theory

Siting Wind climate from the Global Wind Atlas, adjusted for local terrain sector by sector with a linear flow model on an elevation grid around the site. data sources · terrain model
Shearing Handled internally by the Global Wind Atlas, which returns wind climate at hub height. An exponent can be set manually if you have measurements to derive one from. wind shear
Losses Bastankhah Gaussian wake model, direction-weighted by the site wind rose, plus an IEC 61400-15-2 multiplicative loss waterfall (blockage, availability, electrical, curtailment, and more). wake model · losses
Results Weibull-integrated power curve fitted to manufacturer curves, air density from the site's ERA5 temperature, and uncertainty from a root-sum-square of component errors. air density · turbine library

Full derivations, known limitations, and roadmap: Manual.

Data sources. Wind: Global Wind Atlas (GWC), with NASA POWER (MERRA-2, ~50 km) as a fallback. Terrain: Terrain Tiles on AWS (Mapzen and others). Temperature and long-term statistics: ERA5 (Copernicus Climate Change Service) via Open-Meteo.com. Power curve shape: fitted to the OpenEnergy Platform turbine library (ODbL). Map tiles: OpenStreetMap / OpenTopoMap / Esri. Bathymetry: EMODnet / GEBCO. Full credits and licences are in the Manual.
Backend connection
Data service: turbine-yield-backend.onrender.com (fixed). Falls back to clearly-labelled synthetic demo data if unreachable. Free-tier hosting sleeps when idle, so the first request after a quiet period can take up to a minute.
